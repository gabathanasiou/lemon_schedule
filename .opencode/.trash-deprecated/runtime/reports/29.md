# Roadmap 29 — Ribbon block: full designer parity + sample-cell fallbacks

Branch `feat/29` (base `1e376ddf`).

## What changed

- **`src/lib/ribbonUtils.ts`** — added the shared `PREVIEW_SAMPLES` trio
  (INT DAY 5 / EXT DAY 12 / INT NIGHT 20A; previously duplicated in
  `RibbonLivePreview.tsx` and `PrintDialog.tsx`) and the
  `ribbonCellDisplayValue(cell, scene, { sample, customFieldLabels })` helper —
  the single source for ribbon cell display text: real value → sample value
  (`getFieldValueFromSample`, sample scene number included) → field label
  (`FIELD_MAP`/customFieldLabels) with `isValue: false` signalling the
  italic/dimmed label fallback. Affixes apply via `formatCellText` only when a
  value (real or sample) exists. Runtime-imports `getFieldValue`/
  `getFieldValueFromSample` from `ribbonDefaults` (type-only back-import — no
  cycle).
- **`src/components/reports/ReportRibbonView.tsx`** — Part A (parity):
  - deleted the local `fmt`; every cell (strips, daybreak halves, note/break
    rows) now formats affixes through the shared `formatCellText` (strips via
    `ribbonCellDisplayValue`); callTime + duration affixes now render 1:1 with
    the stripboard print pipeline (`PrintRowParts.tsx`).
  - `Strip` renders cell content through `RibbonCellText` (wrap/truncation/
    clamp now honored like the stripboard — before, content was a raw text
    node that wrapped regardless of the cell's truncation settings).
  - note/break `duration` cells keep the print pipeline's `v ? … : ''`
    semantics (no `↑` zero marker — that's a scene-strip affordance) with
    affixes.
  - Part B (samples): `sample = !!previewLimit` gates all sample fallbacks —
    designer canvas and preview only, print (`previewLimit=false`) NEVER
    renders samples. Strip + halves + note/break rows all consume the shared
    helper. Label fallbacks render italic + `opacity 0.5`.
  - Empty project (no days): `SampleSchedule` renders the `PREVIEW_SAMPLES`
    trio as real strips (colored by `sceneStyle` per INT DAY / EXT DAY / INT
    NIGHT) on canvas/preview, replacing the "schedule is empty" hint; print
    still renders nothing.
- **`src/components/ribbon/RibbonLivePreview.tsx`**, **`src/components/PrintDialog.tsx`**
  — import the shared `PREVIEW_SAMPLES` (their local copies deleted).
- **`e2e/report-ribbon-samples.spec.ts`** (new) — empty project renders the
  trio on the canvas (no hint); seeded project renders real values with their
  `Sc` affixes; custom-category cell with no value shows its label in italic +
  reduced opacity.

## Invariants touched

- **Ribbon cells single source** (AGENTS.md "Ribbon Cells"): all cells now flow
  through `getRibbonCellBaseStyle` + `formatCellText`/`ribbonCellDisplayValue` —
  no per-view value/affix code left in the report ribbon view.
- **Print NEVER renders samples** — gated on `previewLimit` (true in
  `ReportDesignerCanvas` and `ReportPreview`, false in `ReportPrint`), so
  pagination budgets and print output are unchanged for real projects
  (verified by `report-pagination.spec.ts` on both engines — budgets, header/
  footer repetition, PDF page count).
- **1:1 parity with the stripboard print pipeline** (`PrintRowParts.tsx`):
  affixes on callTime AND duration in note/break rows; zero/absent durations
  render nothing (not `↑`); truncation/ellipsis via `RibbonCellText` match
  `PrintSchedule.renderSceneCellFlex`.
- **`ribbonUtils.ts` is a shared file** (AGENTS.md "never parallel workers on
  … `ribbonUtils.ts`") — this item explicitly targets it (roadmap cites
  `ribbonUtils.ts:114`), so the change is expected; no other worker was
  concurrently editing it.

## Assumptions (judgment calls)

1. **Sample fallbacks in daybreak halves / note / break rows**: their
   callTime cells route through `ribbonCellDisplayValue` with `sample` enabled
   (satisfying "used by Strip + halves + note/break rows — one source"); on a
   real project these values exist so nothing changes. A genuinely missing
   callTime shows the sample call time / italic label on canvas only — the
   documented preview affordance. Duration cells in note/break rows do NOT get
   sample fallbacks (their zero-duration semantics must stay 1:1 with print).
2. **Affixes apply to sample values too** (matching `RibbonLivePreview`'s
   `val ? c.prefix : undefined`), and are dropped only for the italic label
   fallback.
3. **Print-dialog `RibbonDummyPreview` stays sample-free** — it fabricates its
   own scenes; roadmap scoped samples to canvas + preview.
4. **The empty-project trio is strips-only** (no daybreak halves/note/break
   rows) — mirrors `RibbonLivePreview`; day-break toggles still apply to real
   schedules.
5. **`PREVIEW_SAMPLES` shared** from `ribbonUtils` (de-dupes the existing
   copies in `RibbonLivePreview` + `PrintDialog`); PrintDialog's copy lacked
   `sceneNumber`, which the shared trio adds (unused there).
